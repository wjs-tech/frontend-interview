# frontend-interview · 前端面试复习笔记

> 用生活里的例子把面试题讲通，再把 Vue / React / 新旧版本并排对照，顺便记一点自己踩过的坑。边复习边沉淀，不做八股合集。

这个仓库是我复习前端时一点点攒下来的笔记。它不追求"最全"，只想做到三件事：

1. **先用生活类比讲通**：碰到抽象概念，先找个日常例子（比如用"开店起名"理解标识符和关键字），把门槛降下来；
2. **尽量做对比**：同一个知识点，能对照 Vue 怎么写 / React 怎么写 / 新版本和旧版本差在哪，就并排写出来——这本来就是我自己的学习路径；
3. **带上真实踩坑**：每篇都记"我栽过的地方"和"面试官可能接着问什么"，不端着，也不假装全懂。

更新节奏不固定，但会一直写下去——也正好是我自己的复习轨迹。

内容会持续打磨，也欢迎拍砖。一起把"背八股"变成"真理解"。
